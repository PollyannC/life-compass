# Life Compass

**看清你正在过的生活，与你真正想要的生活之间的距离。**

Life Compass 是一个中文人生探索与复盘 skill。它陪你从不愿走向的未来出发，探索自己在意什么、想成为什么样的人，再通过行动和定期回顾，逐渐找到适合自己的方向。

## 你是否也遇到过这些时刻？

- 你知道有些事情需要改变，却一次次告诉自己「等忙完这段时间」。
- 你反复给自己定目标，可日常生活总把真正重要的事挤到后面。
- 你完成了很多任务，却越来越不确定自己是否正在过想要的生活。
- 你想深入理解为什么卡住，但复盘最后变成了自责，或者又一份做不到的计划。

Life Compass 帮你把模糊的不满、想象中的未来和实际发生的事情放在一起看，找到值得改变的方向，并用真实经历检验下一步。

## 它能带来什么价值？

**看清方向。** 从 Anti-vision（不想走向的生活）入手，逐步探索背后的需要、价值和 Vision（想靠近的生活）。首次探索包含直接、尖锐的问题，邀请你思考如果现有模式继续，两年、五年、十年后，甚至生命结束时，你会如何回望。

**看见言行之间的差距。** 每次复盘对照你说过想做的事情、实际发生的事和现实条件。如果同一个差距反复出现，Life Compass 会直接指出来，和你一起探索原因。

**在行动中建立自我信任。** 把愿景转化为由你选择的小实验，观察什么有效、什么需要调整。每次回顾都会先看有依据的进展，再面对差距，帮助你在真实反馈中积累经验。

**让思考留下来。** 复盘会保存为本地日记和图形快照；通过 Obsidian 兼容的链接，逐渐把愿景、经历、行动和反复出现的主题串起来。图上的关联需要你确认，不能自动视为因果关系。

## 怎样使用更有效？

### 1. 从一次诚实的探索开始

在支持该 skill 的客户端中输入：

~~~text
$life-compass 带我开始第一次人生探索
~~~

从你最在意的不满开始。问题可能很尖锐；你可以慢慢回答、跳过或暂停。尽量用真实经历和具体场景作答，不必一次找到完整答案。AI 负责提问和整理，方向由你判断。

### 2. 把愿景变成一个可尝试的行动

选择一个当前最重要的方向，与 Life Compass 一起确定你愿意做什么、何时做、可能遇到什么障碍，以及做完之后想观察什么。行动不需要很大，但应与你真正想靠近的生活有关。

### 3. 定期回来，比较计划与现实

例如，你可以每两天回来一次：

~~~text
$life-compass 带我复盘：上次我想做的事，实际发生了什么？
~~~

告诉它做到了什么、没做到什么，以及计划之外发生的事情。它会先帮你看见真实进展，再指出差距；如果反复卡住，会和你一起检查目标、任务、时间精力、环境和可能的顾虑，而不是替你断定原因。

### 4. 使用日记和图谱，观察长期变化

每次探索和复盘的日记及图形快照默认保存在 ~/Desktop/Life coach/Journal/；你也可以指定其他位置。在 Obsidian 中打开这个文件夹，可以通过笔记链接回看相关主题。需要时，skill 可以生成画布，帮助梳理具体关系。

定期回看那些反复出现的问题，也看看哪些方法正在帮助你。你可以纠正 skill 的理解，或根据新经历调整 Vision 和目标。

## 开始使用

将仓库中的 life-compass 文件夹复制到客户端的个人 skill 目录。例如，在 Codex 中可放入 ~/.codex/skills/life-compass/，然后刷新 skill 列表或重新打开聊天。也可以让支持本地文件的 AI 直接读取 life-compass/SKILL.md 及其 references/ 目录。

客户端需要具备读取和写入对应本地目录的权限。不同客户端对 skill 发现、对话内图形和 Obsidian 画布的支持可能不同；路径存在不代表已自动安装或获得权限。

## 如何理解它的反馈

Life Compass 会在关键判断处区分**你提供的信息、已有记录、推断、待验证假设、建议和尚不清楚的部分**。例如，「三次记录中没有看到行动」和「你可能担心失败」是不同类型的信息；后者需要你自己判断和检验。

它只了解你分享或允许读取的内容，不替你做人生决定，也不提供心理诊断或治疗。

## 隐私与提醒

日记和图形通常以明文保存在本地，设备备份或既有云同步可能影响它们的存储位置；它们不属于 skill 代码，不应上传到仓库。你与 AI 的对话如何处理取决于所使用的服务。

定时提醒需要另行配置可用的调度和邮箱工具；安装 skill 本身不会创建提醒或保证邮件送达。
